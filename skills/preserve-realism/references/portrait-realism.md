# 人像真实感：结构、光线与局部材质

用于真人外观的近景生成、编辑、塑料感修订与人物对比。按本次素材选择相关要求，避免将所有部位的细节词一次堆入提示词。

## 先确定要保留的审美

确认人物年龄段、气质、造型、妆容、构图及光线。帅气、漂亮、干净肤质和自然淡妆都能保持摄影真实感。编辑已有照片时，保留原人物的脸型与五官关系；不自动套用统一的网红脸，也不把人做老或做出病态来体现真实。

## 判断顺序

1. **结构和辨识**：脸型、眼鼻唇、发际线、表情和姿态是否符合任务；有参考时是否仍像输入人物。
2. **光线和体积**：光源方向、眼部反光、鼻翼与颌下阴影是否相互支持，亮暗处是否仍有层次。
3. **局部材质**：有依据的皮肤变化、眼睑、嘴唇、发束和衣料是否符合当前景别。

前两项有明显问题时优先修正。局部纹理清楚但脸部结构错误的结果不能称为保真。

## 按部位选择要求

| 部位 | 摄影外观的观察依据 | 有问题时的处理 |
| --- | --- | --- |
| 额头、鼻部 | 光泽随受光和曲面变化，亮部仍有柔和过渡 | 减少均匀油亮与硬白高光，不将整张脸压成哑光 |
| 双颊、鼻翼 | 平缓肤色过渡与局部细微变化，明暗处纹理强度不同 | 减少均匀磨平或贴图式毛孔，按原光线保留可见变化 |
| 眼睛 | 有厚度的眼睑、自然眼白明暗、与光源相符的反光、清楚但不过分夸大的虹膜 | 减少玻璃珠感、纯白眼球和发光虹膜，不擅自改变眼型 |
| 嘴唇 | 与表情一致的体积、细纹和局部柔和反光 | 减少塑料涂层、过分光滑的唇线，保留原唇形与妆容 |
| 眉毛、头发 | 可读的毛发走向和粗细分组，发际线有自然过渡 | 避免整块头盔形发型与机械重复细线，不要求根根同锐度 |
| 衣服与颈肩 | 织物、褶皱、接触阴影与皮肤受光协调 | 修正材质混淆或接合，不拿衣服锐度代替脸部可用细节 |

上述是检查依据。没有参考的新生成，可以描述适度自然变化；已有参考的编辑，不能据此凭空添加雀斑、疤痕、痣、胡茬、眼袋或强皱纹。不能把生成补充的纹理称为原始纹理恢复。

## 把目标变成一段有效指令

先保留具体人物、构图与光线，再选择最影响真实感的两三项局部问题。例如：

```text
以提供的胸像为人物和构图参考，保留脸型、五官、表情、发型、衣服及光线方向。让鼻部高光过渡更柔和，双颊在当前柔光下有细微、低对比的肤色与表面变化，眼睑和眼白的明暗与窗光一致。保持漂亮的造型与淡妆，不新增面部标记，不把皮肤锐化成砂纸。
```

原图已自然时可以保留，不为了显示处理而强加细节。用户希望变化更明显时，说明当前实际差异，再决定是否需要不同光线或更近景；这些变化应作为创作选择记录，不冒充保真提升。

## 做可以核对的前后对比

- 使用真实的独立基线调用，保存原始提示词和返回文件。普通提示词也可能生成很自然的结果；不预设基线一定有塑料脸。
- 按基线中实际可见问题形成优化要求，保留人物、构图、场景、光照方向和展示尺度，避免用换脸、变焦或更强曝光制造优势。
- 以基线为身份参考做生成式编辑时，明确记录这一流程；它同时增加了参考输入，不能称为只切换 skill 的严格实验。模型或种子不可控时如实记录。
- 保存优化的独立返回文件。用原始文件做并排展示；如果另用图像工具生成对照板，保留两份原件，注明排版图可能重绘，不能用排版图的细节代替原件检查。
- 不在同一次生成里要求左侧低清、卡通、蜡皮，右侧写实，再称它为使用 skill 的实际效果。
- 在同等显示尺度查看整脸与眼、鼻、唇局部。报告具体变化、仍有的问题和人物漂移；变化不明显或更差时，明确说明，不编造提升百分比或认证分数。

## 适合停止的情况

主体、身份、摄影结构和材质已满足当前任务时交付。一次修订后仍无明确改善，先缩小到实际缺陷，不自动重绘直到出现夸张差异。
