# 图片生成与编辑

在生成写实图片、编辑已有照片或改写相关提示词时读取。检查结果的方法见主文件链接的 `examples-and-review.md`。

## 选择细节依据

| 条件 | 提示词和操作如何调整 |
| --- | --- |
| 人脸近景，原图细节可见 | 保留可见的皮肤变化、细纹和局部标记；不要放大它们的强度 |
| 中景或全身照 | 优先五官比例、自然肤色、头发轮廓与织物表现，不硬加微距纹理 |
| 人物远景、浅景深或暗光 | 让细节符合可见尺度和焦点；避免为了“高清”改成另一个景别 |
| 原图模糊或严重压缩 | 分开描述可观察特征与推测的新细节；增强后要检查是否变脸 |
| 没有原图，从零生成 | 描述自然材质与光照，不声称“保留原图细节”或特定真人身份 |

## 从零生成

### 人物与背景的视觉权重

先确定用户更重视人物还是环境，再决定胸像、腰上、膝上或全身景别。用户明确要求“主体放大、拉近景”时，使用更紧凑的半身或近景，收窄背景范围，保留必要的湖面、山体或天空线索。

人物放大时，按任务需要保留背景的可辨认程度。需要可辨认的景物时，保留相应轮廓与空间关系；收窄背景取景范围，突出主要人物。实际检查人物占比、背景覆盖范围及边缘伸展，将镜头描述与构图结果一起核对。

这条规则仅在符合用户任务时采用，不改变明确要求环境为主或人物远景的构图。

### 组织提示词

将需求组织成以下信息，缺少的不必强行补满：

**主体与任务 → 场景与构图 → 光线与焦点 → 相关材质细节 → 关键风格约束。**

说明摄影外观及与用户需求相符的自然细节。人物不默认变年轻、更瘦、更对称或更“完美”；确实需要造型或修饰时执行用户的具体要求。

例如，要自然的半身人物照片，可以描述柔和窗光、与拍摄距离一致的皮肤变化和真实衣料。不要自动附加微距、满脸毛孔、胶片颗粒和强 HDR。

材质描述随场景选择：

- 皮肤：光照下自然的色彩与表面变化，避免蜡感或不自然的均匀高光。
- 头发：合理的发束、发丝与边缘，不要求远景每根头发都清晰。
- 织物：与裁剪、姿势和受光一致的褶皱与纤维感。
- 金属、玻璃、木材：反光、透光或纹理符合对应材质和场景，不统一添加“颗粒”。

这是描述生成目标的方法，是否达到目标由实际结果决定。

人脸近景或用户明确关注帅哥美女的真实感时，按 [人像真实感](portrait-realism.md) 的判断顺序处理眼睛、局部光泽和皮肤过渡；根据当前问题选择要求，不自动堆叠所有细节词。

## 真人照片编辑

### 将修改与保留分开

先写修改对象、区域和程度，再写保留项。保留项从原图和任务中提取；不能凭空列出实际看不清的痣或其他特征。

| 常见任务 | 允许变化 | 重点保留 |
| --- | --- | --- |
| 换衣服 | 衣服、接触阴影与必要的衣物遮挡 | 面貌、发型、身体结构；姿势按用户要求 |
| 换背景 | 背景、必要的环境光调整 | 五官比例、身份线索、已有可见纹理 |
| 换表情 | 与表情相关的眉眼、嘴部及肌肉变化 | 脸部结构和稳定身份线索 |
| 改姿势或拍摄角度 | 姿态、透视和相应可见部位 | 人物辨识特征；新增可见细节不能冒充原图证据 |
| 增清晰度或放大 | 用户允许的尺寸、降噪及细节增强 | 可辨认结构和原图有效细节；检查生成性补充 |

自然肤色可以随光线变化；保持肤色基调不等于各像素颜色不变。改变表情时也不要求面部几何逐像素一致。

### 选择区域控制

如果工具支持明确的局部编辑、蒙版或区域保护，按其实际用法建议。蒙版语义、边缘处理和未遮罩区域是否会重绘必须依工具确认。

只换背景且要求人脸严格保持时，可建议保留原始人物区域，将编辑结果与原图合成。需要逐像素不变时，还应核对边缘、颜色处理及最终导出；用文字要求“保持不变”并不等于已经做到。

工具没有区域控制时，提供明确的自然语言约束，并说明最终需要对照检查。不要虚构可以点击的开关。

### 多参考图

分别说明图像的角色，例如：

- 图 1：人物身份与原始照片。
- 图 2：衣服的款式和材质。
- 图 3：背景或场景。

说明应从各图迁移的内容，避免把衣服参考中的脸、肤色或摄影风格也迁移进来。只有看到素材或用户明确说明对应关系时，才给具体图号。

## 改写提示词

先保留原提示词中的主体、动作、构图和用户认可的风格；再解决冲突和补充缺失的关键约束。

| 原描述 | 可以怎样具体化 |
| --- | --- |
| “更高清” | 对焦主体、可辨认的衣料或发束；另说明实际尺寸目标 |
| “真人皮肤” | 根据景别描述自然肤色变化及有依据的细节 |
| “不要卡通脸” | 摄影比例、自然五官表现，避免夸大的脸部比例和蜡感表面 |
| “电影感” | 结合用户场景描述布光、色彩或构图；不擅自更换整个画面 |
| “跟原来一样” | 明确哪些身份特征、构图或纹理保持，哪些内容允许修改 |

若用户明确要求“美颜”，询问或从上下文区分润色与改变脸型的程度；不要擅自把用户的目标改成完全无修饰。

## 尺寸与增强

先判断主体和任务是否合格，再讨论输出尺寸。实际宽高以原始文件或可靠元数据为依据，预览放大不是尺寸确认。

放大、降噪或人脸修复可能引入推测性细节。选择方法时区分用户更重视身份保真还是允许合理重建；没有依据时不承诺完整恢复。提升尺寸后复查眼睛、嘴部、发际线、皮肤、衣料及锐化边缘。

不要求每张图使用额外放大步骤。原生输出已满足交付时，保留可用结果。

## 失败修订

- 卡通化：检查是否存在与摄影要求冲突的整体或局部风格描述；重写目标区域的摄影外观。
- 塑料皮肤：检查均匀肤色、过度磨皮和强高光；让细节与光照、景别及原图一致，不以粗大毛孔替代。
- 换脸：回到身份参考和已确认版本，缩小编辑范围，检查参考图职责是否混淆。
- 纹理过强：降低不必要的细节要求，保留原景别、柔光及合理景深。
- 过度锐化或伪细节：先处理实际问题，不继续叠加“超清”或放大要求。

根据实际看到的缺陷选择修订方法；没有素材时把原因写成可能性，不确定地归因于某个模型内部机制。
