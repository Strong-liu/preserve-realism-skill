# 实景拼贴海报：蒸馏说明

> 设计存档：以下记录蒸馏草稿时的范围。该工作流现已纳入仓库 `0.2.0` 的 `skills/scene-zine-poster/`，当前实例与检查状态见 `VALIDATION_V0.2.0.md`。

依据：用户贴出的《Gathered Scenes Zine v1.3》核心处理指令。本文整理其设计方法，不代表读取或验证了同名 GitHub 仓库，也不涉及原帖对各平台模式与功能的宣传结论。

交付：`scene-zine-poster` 独立草稿，用于审阅和后续创作。本轮不生成新海报。

## 一句话核心

让照片中的一个真实主体成为情绪锚点，以顺应场景结构的撕口连接摄影和抽象插画，再用留白、单一强调色与纸墨质感完成视觉叙事。

## 值得保留的设计方法

1. **撕边有依据**：轮廓、透视动线或焦点决定边界，避免所有照片套同一种撕纸框。
2. **真实与抽象各有职责**：摄影提供可辨认的场景，插画把原图的形态延展为更简洁的视觉语言。
3. **跨界元素组织视线**：强调色和墨线承担连接作用，画面不同材料之间有联系。
4. **留白参与叙事**：空白可以表达安静、距离、开放和呼吸。
5. **材质受到控制**：纤维、油墨和微型机打文字共同形成平面手工印刷感。

## 蒸馏版补充的判断

| 原规则需要解释的地方 | 蒸馏后的处理 |
| --- | --- |
| 没有明确主题大小 | 先确定主体景别和视觉权重，再处理景物与装饰 |
| 没有说明情绪怎样落到画面 | 将情绪转成空间、动势、对比和疏密选择 |
| 三种撕口可能同时堆叠 | 选择一种主导逻辑，其他处理只服务构图 |
| “60%–75% 插画”可能被理解成满版涂画 | 纸面场域包含留白，比例作为起点，主体可读性优先 |
| “只有一种强调色”可能损伤照片色彩 | 限制新增图形层的强调色，摄影区保留原色 |
| “禁投影”可能误删照片光影 | 新增图形保持二维，照片内部自然光影保留 |
| “禁数字蒙版”可能误伤执行方式 | 限制干净几何硬切的观感，允许蒙版等制作手段 |
| 纸张纹理可能覆盖整张人像 | 材料感主要落在纸面，摄影主体保留自然皮肤与细节 |

## 对上一张游客照的反馈

上一张采用了膝上构图，湖景覆盖范围较大，与用户期望的主体放大、取景拉近不符。

后续人物创作需要先确定：主体应该多大、拍到哪个部位、背景保留多少。用户明确要求拉近时，优先使用紧凑半身或近景，收窄背景范围，保留必要地点线索；生成后检查实际视觉权重。

这条反馈用于当前对话的后续创作，并纳入新 skill 的构图判断。本轮未更改已安装的 `preserve-realism` 文件，也未重做上一张图片。

## 后续如何提出创作任务

例如：

> 创作实景拼贴海报，使用这张照片，传达安静、自由的情绪。人物要突出，画面横向 16:9。

或：

> 创作实景拼贴海报，主题是老街的一扇窗，情绪是怀旧、克制，竖版。由你选择撕口、强调色与微型文字。

收到主题、情绪和素材后，依次确定主体、撕口、跨界连接和留白，再执行创作。比例或文案已有要求时沿用；没有要求的设计选择由画面和情绪决定。
