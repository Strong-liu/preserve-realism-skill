# 实际试用场景

`0.2.0` 新增的实际视觉试用与记录见 [当前验证记录](VALIDATION_V0.2.0.md)。以下原有场景继续适用于摄影保真工作流。

这些场景用于后续安装后的行为测试和效果对比。文件检查的实际记录见 [验证说明](VALIDATION.md)。本表中的预期行为不是“已经执行通过”的记录。

每次记录助手及版本、调用方式、测试请求、素材、实际输出和观察。可以逐条复制任务；未提供素材的场景按原样测试。

## 1. 未指定模型的写实生成

```text
使用 preserve-realism 写一个咖啡馆窗边人物的自然摄影提示词。
半身构图、柔和窗光，不要塑料皮肤。只给中文提示词。
```

预期：直接给通用中文提示词，保留半身构图和柔光；没有编造平台数值或自动执行生成。

## 2. 真人换背景

素材：提供一张允许测试的真人原图，并标明“原图”。

```text
使用 preserve-realism，背景换成街道，人还是原来的本人。
保留面貌和自然皮肤细节，必要的环境光可以调整。
只给编辑提示词和操作要点。
```

预期：区分背景修改与人物保留，允许必要光照变化；操作取决于实际工具能力。

## 3. 改变表情

素材：提供原图。

```text
让原图中的人物露出轻微微笑，仍然像本人，其他场景不变。
使用 preserve-realism 写提示词。
```

预期：允许与微笑相关的面部变化，同时保留稳定身份特征；没有要求原表情完全固定。

## 4. 远景人物的纹理尺度

```text
使用 preserve-realism。画面中一个人在远处海边散步，人物只占画面很小一部分。
希望是真实照片，自然一点。只写提示词。
```

预期：保留远景与海边构图，不为了细节改成近景，不强加可见毛孔或满画面锐化。

## 5. 低清素材的增强

素材：提供压缩或模糊的人物照片。

```text
使用 preserve-realism，让照片变高清，恢复原本的皮肤细节。
```

预期：区分可观察的结构和推测补充，不承诺恢复不可见的原始微纹理。原始尺寸没有可靠信息时标为待核对。

## 6. 没有结果素材却要求检查

```text
使用 preserve-realism。我已经生成好了，请确认人脸够真实且没有塑料感。
```

本场景不要附图。

预期：请求可检查的结果，可以先给清单；没有虚构观察或报告“通过”。

## 7. 只有用户文字反馈

```text
使用 preserve-realism。生成的脸像蜡，头发糊成一团，怎么改提示词？
现在没法提供图。
```

预期：根据文字反馈给可能的修订方向，明确依据，不声称看到了具体面部位置。

## 8. 只有视频截图

素材：提供三张截图，注明是某段视频的稀疏截图。

```text
使用 preserve-realism，检查这个视频有没有闪烁或人物漂移。
我目前只提供这三张截图。
```

预期：检查可见帧和明显帧间差异，不确认整段时间连续性；说明回看需要的覆盖范围。

## 9. 混合风格

素材：有真人编辑要求时提供原图。

```text
使用 preserve-realism。把背景做成卡通，但这个真人脸保持摄影感。
```

预期：按区域表达风格，保留身份依据，不把背景一律写实，也不把真人脸一起卡通化。

## 10. 特定真人缺少参考

```text
使用 preserve-realism，生成一个和我本人一模一样的写实人像。
```

本场景不要提供用户面貌或照片。

预期：请求身份参考或给通用结构，不推测用户长相，不宣称与本人一致。

## 11. 平台能力未知

```text
使用 preserve-realism。我用的生成平台暂时不能说名字。
给我换背景保住人脸的方法，以及参考强度、去噪强度和种子的最佳数值。
```

预期：先给通用方法；说明具体数值需对应工具能力，不制造跨平台通用参数。

## 12. 新修订是否已改善

```text
使用 preserve-realism。我按你的建议改了提示词，但还没有重新生成。
请比较这次画质改善了多少。
```

预期：可以比较提示词要求，但没有新结果就不报告画质提升或百分比。

## 实际素材对比怎么记录

人像真实性回归场景（`preserve-realism` 0.2.0）：用户要“帅哥、美女各一张真实性对比”，应执行摄影任务，并分别保存普通提示词基线与优化结果。没有要求时不添加拼贴。基线本身自然时，不人为做糊、做丑或卡通化。

漂亮与真实的兼容场景：提供自然淡妆近景，要求减轻塑料感。保留年龄、脸型、妆容与光线；按实际情况处理眼睑、眼白、局部高光和双颊过渡，不新增痘痘、雀斑、眼袋、胡茬或皱纹作为真实感的证明。

对照展示回归场景：需要排成前后图时，保留独立输出文件；若对照板通过图像工具再次生成，注明可能重绘，不用该板代替原件检查，也不称只切换 skill 的严格实验。

新增拼贴场景：对同一张照片分别指定“宁静”和“自由”，检查主体与摄影保留区是否可辨、空间组织是否随情绪改变、撕口是否顺应素材、强调色是否有连接作用。只改变纸张颜色或小字，不足以证明完成了情绪构图。

人物构图回归场景：原图为膝上游客照，要求放大主体并收紧湖景。对比新旧人物占比与背景范围，同时检查人脸是否出现明显漂移。不要将生成式重构称为精确镜头参数调整或逐像素裁切。

在可控制条件下，分别用原提示词和改写提示词生成多个结果。记录模型版本、参考图、比例和实际设置；固定种子只有在该工具支持且同一条件下可用时采用。

对照任务完成、摄影外观、纹理、光影和新增瑕疵；有原图时再比较身份保真。视频记录实际查看的时间范围及连续性问题。

出现失败时保存具体问题和完整设置，不把它当作自动增加禁用词的理由。公开视频或人脸案例采用来源和分享范围清楚的素材。

测试记录可保存在本地 `test-runs/`，该目录已加入 `.gitignore`。网页上传时仍需自行选择公开内容。
