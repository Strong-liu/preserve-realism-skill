# 0.3.0：人物真实感修订与实例验证

## 版本

- 仓库版本：0.3.0。
- `preserve-realism`：0.2.0。
- `scene-zine-poster`：0.1.0，本轮未修改。
- 许可：沿用 MIT。

## 为什么修改

用户明确希望优化人物的摄影真实感，并要求帅哥和美女各一组对比。此前任务曾被路由到实景拼贴；这轮将人物真实性与拼贴的选择条件写清，并增加具体的局部观察依据。

新增的人像参考文档按结构、光线、局部材质决定修订顺序，区分额鼻高光、双颊过渡、眼睑与眼白、唇纹、毛发和衣料。保留帅气、漂亮、年龄与自然妆容，避免靠强毛孔、痘痘、胡茬或衰老制造真实感。

## 已执行的例子

每组先以普通短提示词独立生成基线，再以该基线为人物和场景参考进行一次编辑，最后生成便于浏览的并排板。独立原件与实际提示词另行交付，未将大图加入本次仓库提交。

| 例子 | 实际观察 | 判断 |
| --- | --- | --- |
| 成年男子胸像 | 五官、发型和场景总体接近，皮肤变化很小，衬衫纹理更强 | 两张均有摄影外观，不支持显著真实感提升 |
| 成年女子窗边胸像 | 脸型、微笑和淡妆总体保留，额头细纹、发丝与衣料更明显，局部纹理略显刻意 | 仅小幅材质变化，不能认定整体明显更真实 |

本轮为生成式编辑实例，优化调用增加了参考图；模型名称与种子未固定。不能称为仅切换 skill 的严格因果比较，也不能将新增纹理当作真实细节恢复。

对照板由图像工具再次排版，可能发生重绘，核对依据是独立原件和直接显示原件的 HTML。没有要求基线变糊、卡通化、变丑或过度磨皮。

## 文件与规则检查

`quick_validate.py` 对新版摄影 skill 检查通过；独立审阅确认新增规则按当前任务与可见缺陷选用，没有强制粗毛孔或降低人物审美。交付前核对相对链接、许可副本、UTF-8 与元数据。

文件和规则检查通过，不代表画质提升已经证明。原图已自然时保留它；后续修订应缩小到实际缺陷，而非反复增加形容词或重绘直到出现夸张差异。
